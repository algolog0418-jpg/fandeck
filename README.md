# FanDeck

[English](README.en.md) · 한국어

맥 온도 모니터링 + 팬 제어 앱. Apple Silicon 용 무료 오픈소스.

만든 곳: **ALGOLOG**

> **검증 기기**: M4 Mac mini(Mac16,10), macOS 27.
> 다른 맥에서도 동작하지만 센서 이름은 이 기종에서만 확인했다 ([기종 지원](#기종-지원) 참고).

Macs Fan Control 을 대체하면서, 활동 상태 보기 기능까지 한 앱에 합쳤다.
라이선스는 MIT, 안전 관련 주의사항은 [SAFETY.md](SAFETY.md) 에 있다.

## 쓰는 법

1. `build/FanDeck.app` 을 실행한다 (응용 프로그램 폴더로 옮겨도 된다).
2. 처음 열면 암호 창이 한 번 뜬다. 입력하면 팬 제어가 켜진다.
   - macOS 는 팬 속도 변경에 반드시 관리자 권한을 요구한다. Macs Fan Control 도 같은 방식이다.
   - 취소해도 **온도·CPU·메모리 보기는 전부 정상 동작**한다. 팬 속도만 못 바꾼다.
3. 다른 팬 제어 앱(Macs Fan Control 등)이 켜져 있으면 서로 팬을 뺏으므로 하나만 쓴다.

터미널에서 쓰고 싶으면 `fandeck status`, `fandeck set 1800`, `fandeck watch` 등이 있다.

## 온도 값에 대해

Apple Silicon 은 코어 하나당 센서가 2~3개 있다. 예를 들어 성능 코어 1 은

- `Tp00` 주변부 — 코어를 둘러싼 비교적 낮은 지점
- `Tp01` **코어 다이** — 다른 팬 제어 앱들이 "CPU Performance Core 1" 로 표시하는 값
- `Tp02` 핫스팟 — 같은 영역에서 가장 뜨거운 지점. 코어 다이보다 10도 이상 높다

이 앱은 **코어 다이(`Tp01`)** 를 코어 온도로 쓴다. 다른 앱과 숫자가 맞는다.
핫스팟은 "성능 코어 1 핫스팟" 으로 따로 보여주고, 과열 보호에는 핫스팟 기준(`CPU 핫스팟`)을 쓸 수 있다.
센서 목록에는 항상 원래 SMC 키가 같이 표시되므로, 어떤 값인지 직접 확인할 수 있다.

## 기종 지원

코어 센서 묶음(`Tp00`/`Tp01`/`Tp02` → 성능 코어 1 등)은 M4 Mac mini 에서 실측해 정한 것이다.
다른 맥에서는:

- 없는 키는 그냥 건너뛴다. 그 그룹이 비어 보일 뿐 고장나지 않는다.
- **배치가 다르면 추측으로 이름을 붙이지 않는다.** 모르는 센서는 "기타" 에
  원래 SMC 키와 값 그대로 나온다. 틀린 이름을 보여주는 것보다 낫다.
- 팬 개수는 SMC(`FNum`)에서 읽으므로 팬이 여러 개인 맥북도 처리된다.
- Intel 맥은 키 이름과 `fpe2` 고정소수점 형식이 다른데, SMC 계층은 지원하지만 이름은 미검증이다.

**다른 기종 결과를 알려주면 반영한다** — `fandeck sensors` 출력과 `sysctl -n hw.model` 값을 이슈로 올려 달라.

## 구조

```
Sources/FanDeckCore   SMC 접근(C+Swift), 센서 카탈로그, 커브 엔진, 시스템 모니터, 통신 규약
Sources/FanDeck       SwiftUI 앱 (메뉴 막대 + 창)
Sources/fandeckd      백그라운드 제어 프로그램 (root). 팬 제어와 기록을 맡는다
Sources/fandeck-cli   터미널용 CLI
Scripts/build.sh      Xcode 없이 Command Line Tools 만으로 전체 빌드
```

팬 제어는 root 권한이 필요해서 백그라운드 프로그램이 맡고, 앱은 유닉스 소켓으로 요청만 보낸다.
덕분에 앱을 꺼도, 로그인하기 전에도 설정한 커브가 유지된다.
그 프로그램이 종료되거나 제거될 때는 **반드시 팬 제어를 macOS 에 돌려준다**.
